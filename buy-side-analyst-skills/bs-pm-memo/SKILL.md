# PM-ready memo workflow

## Inputs
- Research notes, model output, valuation, catalyst plan, risks, source list, and requested stance: long, short, watchlist, avoid, trim, add, or neutral.

## Process
1. Identify the decision the memo supports: initiate, add, trim, exit, pass, monitor, or request more diligence.
2. Compress to decision-relevant facts only.
3. Lead with answer first: thesis, expected return drivers, downside, confidence, and what changes the view.
4. Include only the most important evidence, valuation, catalysts, and risks.
5. Translate analysis into portfolio language: sizing, timing, liquidity, correlation, crowding, and risk controls if supplied by user.
6. End with action items and open questions.

## Output format
- One-line decision
- 150-word executive summary
- Thesis in 3 bullets
- Variant perception
- Valuation/upside/downside table
- Catalysts and timing
- Top risks and kill criteria
- Open questions / next steps

Default to concise. Avoid long educational explanations unless the user asks.
