# Earnings call analysis workflow

## Inputs
- Earnings release, call transcript, slides, supplemental KPIs, filing, model, prior-quarter notes, and user-supplied consensus or expectations.
- Ask for prior expectations if not supplied; otherwise infer only from the provided source set and label as incomplete.

## Process
1. Build the expectation vs reported vs guide table for revenue, gross margin, EBITDA/EBIT, EPS, FCF, segment KPIs, and key operating metrics.
2. Separate one-time items from underlying performance.
3. Identify estimate-changing information: guidance, backlog, pricing, cost inflation, demand, churn, pipeline, supply constraints, capex, cash conversion, and capital allocation.
4. Extract management tone shifts and compare against prior language if prior transcripts are available.
5. Summarize Q&A: analyst concerns, management pushback, evasions, new disclosures, and repeated questions.
6. Map read-throughs to peers, suppliers, customers, and adjacent sectors.
7. State what changes in the thesis, what does not change, and what needs verification.

## Output format
- Bottom line in 5 bullets
- Beat/miss/raise/lower table
- Guidance bridge
- Segment/KPI analysis
- Tone and disclosure changes
- Thesis impact
- Follow-up questions for management or IR
- Model update checklist

Do not invent consensus numbers. If consensus is absent, label the comparison as “reported vs user-supplied prior expectation unavailable.”
